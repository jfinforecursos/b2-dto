Haz clic en los botones para disparar excepciones a propósito en Spring Boot y ver cómo el frontend captura el JSON devuelto por GlobalExceptionHandler.

HTTP 400 Bad Request

Regla: Email Duplicado

Intenta registrar un cliente con el correo juan.perez@example.com que ya existe en la base de datos sembrada.

HTTP 400 Bad Request

Regla: Monto de Pedido Inválido

Intenta crear un pedido con total negativo (total: -50). El servicio validará la regla de negocio.

HTTP 400 Bad Request

Regla: Pedido sin Cliente

Envía cliente: null. El backend rechazará la petición indicando que debe tener un cliente válido.

HTTP 404 Not Found

Excepción: Cliente Inexistente

Llama a GET /api/clientes/9999. El backend lanzará RecursoNoEncontradoException.

HTTP 404 Not Found

Excepción: Pedido Inexistente

Llama a GET /api/pedidos/9999 para verificar el manejo del 404 en la entidad Pedido.
